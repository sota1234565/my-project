# 政策提言 Canva用レイアウト

Canvaデザイン「政策提言」(DAHS0X2Q2Hc) のレイアウト改善版。
授業で受けた指摘（文字数過多・型が不統一・写真が小さい・キャプションがない）に対する答えとして、
全ページ共通の3段フォーマットに作り直したもの。

## 成果物
- `out/政策提言レイアウト.pdf` — Canvaに読み込む本体（20ページ / 1123 × 794 px）
- `out/pages/*.png` — 各ページのPNG（PDFが崩れた場合の保険）

## 構成
| ページ | 内容 |
|---|---|
| 01 | 表紙・使い方 |
| 02 | 指摘 → どう直したか |
| 03 | 3段フォーマットの寸法（定規） |
| 04-08 | マスター A〜E の空の雛形 |
| 09-20 | 現在の政策提言12ページを新レイアウトで再構成 |

## 3段フォーマット
- BAND 1 / 結論（高さ190px・42px w900・25字以内）＋ マゼンタ9pxの区切り線
- BAND 2 / やったこと（高さ286px・写真440×240＋キャプション ／ 提言内容・提言相手・提言理由 各40字以内）
- BAND 3 / 得たこと（高さ182px・相手の発言を引用21px ＋ 自分の一言18px）

## 注意
背景の会議室写真は、Canvaの画像ホストがegressポリシーで遮断されているため取得できなかった。
PDFでは背景を透明にし、暗幕（黒80%）と緑の縁だけを載せてある。
Canva側でページ背景に写真を敷けば、従来と同じ見た目になる。

## 再生成
```
/opt/pw-browsers/chromium-1194/chrome-linux/chrome --headless --no-sandbox --disable-gpu \
  --print-to-pdf-no-header --no-pdf-header-footer --virtual-time-budget=20000 \
  --print-to-pdf=out/政策提言レイアウト.pdf "file://$PWD/src/layout.html"
```
