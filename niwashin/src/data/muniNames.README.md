# muniNames.json — 全国市区町村コード表

市区町村コード（5桁）から名前を引くための表。1,902件、47都道府県すべてを収録。

国土地理院の逆ジオコーダーは市区町村を「コード」で返すため、名前に直すのにこの表が要る。
`geocode.js` から遅延読み込みされる（初回に住所を取るときだけ読む）。

## 出典

総務省統計局「市区町村別メッシュ・コード一覧」

このデータは **クリエイティブ・コモンズ 表示 4.0 国際（CC BY 4.0）** で提供されている。
https://creativecommons.org/licenses/by/4.0/deed.ja

出典の表示が利用条件なので、アプリ内にも明記すること（`src/tiles.js` の
`MUNI_ATTRIBUTION`。地理院タイルの出典と同じ扱い）。

npm パッケージ jp-city-lookup（MIT / Yusuke Kawasaki）の dist/city.json から取り出した。
パッケージ本体には 2MB のメッシュデータが含まれており、依存に加えると重いため、
この表だけを取り込んでいる。

## 注意

- キーは**ゼロ埋め5桁の文字列**。数値に変換すると北海道〜沖縄の `01xxx`〜`09xxx` が壊れる
- 2023年ごろのデータ。以降に合併した自治体は表に無い。
  その場合 `geocode.js` は Nominatim から名前を補う
- 政令指定都市は区ごとに入っている（例 `14101` 横浜市鶴見区）。
  親市のコード（`14100` など）は無いが、逆ジオコーダーは区のコードを返すため問題ない
