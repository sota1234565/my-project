遮断されているため、検索結果ベースで作成。最終確認は必ず公式サイト・入試要項で行うこと。

## 0. 出願の実務情報（2027年度 自由選抜入試）

- Web出願: 2026/9/1〜9/10 ／ 書類送付締切: 9/11
- 環境学部の第2次選考日: 11/14 ／ **第2次選考は面接のみ（小論文なし）**
- 募集人員: 約30名
- 出願資格の目安: 全体の評定平均 3.8 以上／英語4技能外部試験
  （英検・TEAP・TEAP CBT・IELTS(Academic)・TOEFL iBT・GTEC・ケンブリッジ英検、
  出願期間初日から遡って2年以内）／かつ以下いずれかの成果
  1. 自然科学分野・環境学分野の研究・探究活動での優れた成果
  2. 環境関連分野や社会課題・地域課題に関連する活動での優れた成果
  3. 学術・文化・芸術分野での高い評価
  4. スポーツ分野で都道府県レベル以上の大会ベスト8以上
- 提出書類: 志望理由書（2テーマ合計1,500字程度）／活動報告書（A4片面2ページ以内）ほか

## 1. 志望理由書の課題（表紙PDFの記載どおり）

- 手書き: 原稿用紙A4横書き 20字×20行、黒または青のボールペン（消せるものは不可）
- PC: A4横書き **40字×30行・11pt**
- 日本語／志願者本人が作成／指定の表紙を必ず使用（左上をホチキス留め）
- **(1)** 強い関心を持っている環境課題と、それに関心を持つに至った理由を、
  **自身のこれまでの経験・見聞をもとに** 記入
- **(2)** **環境学部の教育の特徴やカリキュラムなどを参照し**、志望理由と、
  入学後に何をどのように学んでいきたいかを記入
- 合計 **1,500字程度**。配分の目安は (1)700字前後 / (2)800字前後

## 2. 学部の基本情報

- **環境学部 環境学科**（1学部1学科、コース制ではない）
- 2026年4月開設 ／ **池袋キャンパス**
- 入学定員 **204名**（収容定員816名）
- 文系・理系を問わず募集する **文理融合** 学部
- 基幹教員 **18名**、文系・理系がほぼ半数ずつ
- 掲げる人材像: **新しい時代の「環境リーダー」**（GX・カーボンニュートラルに貢献）

## 3. 教育の3本柱

1. 文理の枠を超える **多角的な視点と多様な視座**
2. 現実の課題と結びつけて活用できる **専門性**
3. さまざまな人とつながる **対話と協働の実践力**

「環境」をメインテーマとする文理融合の **リベラルアーツ教育** ＋ 立教独自の **リーダーシップ教育**。

## 4. カリキュラム構造（積み上げ型）

| 区分 | 内容 |
|---|---|
| 初年次科目（必修） | `リベラルアーツとしての環境学原論` / `環境科学入門` / `環境フィールドスタディ`。環境学の全体像とリーダーシップを最初に学ぶ |
| 基幹科目 | 環境課題の多角的なとらえ方＋人文社会科学／自然科学それぞれの基礎 |
| 実践科目 | 国内外の"現場"により深く入るフィールドワーク、野外活動スキル、企業・地域・行政と連携した**プロジェクト型演習** |
| 発展科目 | 人文社会科学・自然科学にまたがる **50以上** の科目から関心に応じて選択し専門性を深める |
| 集大成（4年次） | **卒業論文**（学術的研究）か **卒業プロジェクト**（環境課題解決の実践）を選択 |

### 環境フィールドスタディ（1年次全員必修）
少人数グループに分かれ、**異なる専門性を持つ複数の教員とともに国内の地域を訪れ**、
実際の地域課題や現地の自然環境をテーマに、現場の取組と人々から学ぶ。

### リーダーシップ教育（立教の看板／経営学部BLPの系譜）
- **経験学習型**: 企業や地域社会等と連携したプロジェクト型演習
- **知識スキル型**: リーダーシップに関する知識・スキルの修得
- 権限によらないリーダーシップ ＝「対話」と「協働」を導く力

## 5. 扱う専門分野（志望理由書で名指しできる領域）

環境化学／生態学／気候学／食品科学／物質循環学／都市環境学／環境教育学／
環境経済学／環境社会学／環境政策学／環境法学／環境文学 など

教員例: 二ノ宮リム さち 教授（環境教育学・ESD論／持続可能な社会を創る教育と学習のあり方）

## 6. アドミッションポリシー（求める学生像の要旨）

- 社会や世界で起きている現象、地球環境の変化に関心をもつ
- **広い視野と複数の視点** から問題を発見し、その解決に向かう意志と態度をもつ
- **多様な価値観・立場の人々と協働** しようとする姿勢をもつ
- 文系・理系にとらわれず幅広い分野に関心をもつ

## 7. 添削の評価軸（採点者目線）

| 観点 | 見るポイント |
|---|---|
| A. 当事者性 | 環境課題が一般論でなく**自分の経験・見聞**に根ざしているか（(1)の必須要件） |
| B. 問いの解像度 | 主体・場所・対立する利害まで具体化されているか |
| C. 文理融合の必然性 | 自然科学の理解と社会科学の理解の**両方**を要する課題だと示せているか＝この学部でなければならない理由 |
| D. カリキュラム接続 | 必修3科目→基幹→実践→発展→卒論/卒業プロジェクト、と**科目名を挙げて4年間の筋道**を描けているか |
| E. 対話と協働 | 立場の異なる人と協働した経験、または協働する構想があるか |
| F. 独自性 | 他の受験生と入れ替え可能な文章になっていないか |
| G. 一貫性 | (1)の課題 →(2)の学び →将来像 が一本の線でつながっているか |
| H. 形式 | 1,500字程度、指定書式、誤字脱字、一文の長さ、学部情報の事実誤りゼロ |
